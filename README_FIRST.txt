SPICY SUGARS EVENT AND ENTERTAINMENT — WEBSITE PACKAGE
======================================================

WELCOME
This is a complete, responsive static website. You do NOT need to know coding to change the common content.

HOW TO OPEN THE WEBSITE
1. Extract the ZIP file (right-click it and choose "Extract All" on Windows).
2. Open the extracted "spicy-sugars-website" folder.
3. Double-click index.html. It should open in your browser.
4. Keep the internet connected for the optional Google Fonts. The website itself is local.

IMPORTANT: This local preview is not automatically public on the internet. To publish it, upload the extracted folder to a static website host (for example Netlify, Cloudflare Pages or your hosting provider) or ask your web developer/hosting provider to publish it.

CHANGE YOUR LOGO
1. Open assets > images.
2. Replace logo.svg with your own logo file, preferably a transparent PNG named logo.png.
3. If you use PNG, open index.html in Notepad and change each "assets/images/logo.svg" to "assets/images/logo.png".
   (You can keep the provided logo.svg if you prefer the starter logo.)

CHANGE ARTIST PHOTOS
1. Open assets > images > artists.
2. Replace each placeholder file with your own approved photo, keeping the EXACT same filename:
   dj-rajesh.jpg
   dj-naaz.jpg
   dj-mavi.jpg
   shreya-ghoshal.jpg
   vishal-mishra.jpg
   the-local-train.jpg
   fossils.jpg
   anupam-roy.jpg
3. Best photo shape: portrait / vertical (about 4:5). Use JPG or WebP, but if using a different file type, you must also change that filename in index.html.
4. Only publish artist names/photos you are authorized to use. A name appearing in the sample is not a confirmation of representation or availability.

CHANGE EVENT PHOTOS
Open assets > images > events and replace these files with your own approved photos:
- live-entertainment.jpg
- weddings.jpg
- dj-stage.jpg
Recommended: landscape images, at least 1400 pixels wide.

CHANGE PHONE / WHATSAPP / EMAIL
The sample site uses contact details found on your reference site. Confirm they are correct before publishing.
- Main email: spicysugersinfo@gmail.com
- Partnership email: spicysuger.partner@gmail.com

To change details, open index.html in Notepad (right-click > Open with > Notepad), then use Ctrl+H (Find and Replace).
Replace the old email/number with the new one. For WhatsApp, the URL uses digits only with country code, e.g. https://wa.me/919876543210.
The email enquiry form opens the visitor's default email app; it does not send messages silently or store enquiries in a database.

CHANGE ARTIST NAMES / TEAM / REVIEWS
You can edit the visible words in index.html with Notepad. Use Ctrl+F to find the current name or heading and replace it. Save the file and refresh the browser.
Please replace example testimonial wording with genuine approved reviews before launch.

CHANGE BRAND NAME / LOCATION
Open index.html with Notepad and use Ctrl+H to replace "SPICY SUGARS", the agency name, or location details as needed. Keep a backup before making many changes.

FOLDER GUIDE
index.html               Main website content
style.css                Colors, layout, typography and responsive design
script.js                Mobile menu, artist filters, enquiry form behavior
assets/images/logo.svg   Starter logo
assets/images/artists/   Artist photo placeholders (replace these)
assets/images/events/    Event photo placeholders (replace these)

TROUBLESHOOTING
- If a photo does not appear, check that the filename and extension exactly match the list above.
- If a changed photo doesn't show, refresh with Ctrl+F5.
- If the email form doesn't open, configure a default email app, or change the form to a hosted form service before launch.
- Before publishing, check all contact details, image rights, artist representation/availability, testimonials and any legal/privacy requirements.
